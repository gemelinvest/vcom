אפליקציית שיחות קול בעברית. נפתחת בדפדפן האייפון ואפשר להוסיף אותה למסך הבית.

## קישור לשיתוף בוואטסאפ

**https://vcom.web.app/**

הכתובת הקצרה מציגה את השם VCOM, ואחרי הלחיצה נפתחת אותה אפליקציה כמו קודם (`voip-call-app-7d0c3.web.app`) בלי שינוי במסכים או בחשבונות.

באייפון: Safari → הקישור → כפתור השיתוף → **הוסף למסך הבית**.
