# VCOM — דמו לאייפון

אפליקציית שיחות קול בעברית. נפתחת בדפדפן האייפון ואפשר להוסיף אותה למסך הבית.

## קישור לשיתוף בוואטסאפ

**https://vcom.web.app/**

הכתובת הקצרה מציגה את השם VCOM, ואחרי הלחיצה נפתחת אותה אפליקציה כמו קודם (`voip-call-app-7d0c3.web.app`) בלי שינוי במסכים או בחשבונות.

באייפון: Safari → הקישור → כפתור השיתוף → **הוסף למסך הבית**.

## אנדרואיד

קובץ ההתקנה: [android/VCOM.apk](android/VCOM.apk).

בטלפון: פותחים את הקובץ ומאשרים התקנה ממקור לא ידוע. האפליקציה נפתחת אל האתר החי, אז שינוי במסכים או בשיחות מופיע בפתיחה הבאה אחרי שהאתר מתפרסם, בלי קובץ חדש.

כדי שהאפליקציה תיפתח בלי שורת כתובת, צריך לפרסם את [.well-known/assetlinks.json](.well-known/assetlinks.json) לאתר `voip-call-app-7d0c3.web.app`. הפרסום הנוכחי ב-Firebase מעלה רק את תיקיית `share` אל `vcom`.
